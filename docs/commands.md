# Command catalog

Generated from `cli/registry.py`; run `make docs-check` to detect drift.
Use `creative-research <command> --help` for options and required inputs.

## Capture & export

- `run`: Run or resume capture, download, export and validation.
- `scrape`: Capture public TikTok records through Apify.
- `download-media`: Download videos, slides, covers and avatars.
- `export-dataset`: Package source records and local media as a portable dataset.

## Project utilities

- `init`: Create capture workspace directories.
- `doctor`: Check capture/download dependencies.
- `status`: Summarize crawl, media and dataset files.
- `validate`: Verify exported dataset records, assets and checksums.
